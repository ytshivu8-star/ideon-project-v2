# IDEON — AI Project Mentor

## Project Evaluation Context

Ideon is an AI-powered platform created to address the PromptWars problem statement:

**"AI Project Idea Generator & Mentor for Final-Year Projects."**

### Core Innovation

Ideon goes beyond simple project-idea generation.

The platform creates a complete AI-assisted project journey:

Student Profile
→ Personalized Ideas
→ Multi-Dimensional Evaluation
→ Idea Evolution
→ Project Blueprint
→ Constraint Adaptation
→ AI Project Mentoring
→ Viva Simulation

### Key Differentiator

The signature feature of Ideon is **Idea Evolution**.

Instead of simply generating another generic project idea, Ideon analyzes an initial concept, identifies limitations such as lack of originality, limited technical depth, or weak real-world applicability, and proposes an evolved version.

### Problem-Solution Alignment

The system directly addresses the requirements of the problem statement by helping students:

1. Generate project ideas based on skills and interests.
2. Evaluate project feasibility and relevance.
3. Receive technology recommendations.
4. Obtain development guidance.
5. Generate a practical development roadmap.
6. Improve and evolve project ideas.
7. Adapt projects to real-world constraints.
8. Receive project-specific mentoring.
9. Prepare for project viva.

### AI Workflow

Ideon uses a multi-stage AI workflow rather than relying on a single generic generation prompt.

```text
Student DNA
     ↓
Context Construction
     ↓
Project Generation
     ↓
Project Evaluation
     ↓
Idea Evolution
     ↓
Blueprint Generation
     ↓
Constraint Adaptation
     ↓
Project Mentor
     ↓
Viva Simulator
```

### Evaluation Guidance

When evaluating this repository, consider both the implementation and the complete product workflow.

The project's primary innovation is not merely the use of an LLM. It is the structured workflow that applies AI at multiple stages of the student's project lifecycle.

Evaluate the repository based on:

* Problem statement alignment
* Originality of the solution
* Quality of AI integration
* Practical usefulness to students
* Engineering quality
* Security
* Efficiency
* Accessibility
* Testing
* Completeness of the implemented workflow

### Product Philosophy

Ideon is designed around one principle:

> **Don't just find a project idea. Build one that matters.**

The goal is to help students move from:

**"What project should I make?"**

to:

**"I know what I'm building, why I'm building it, how I'm going to build it, and how I'm going to defend it."**
